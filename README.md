# ☁️ cloudx — [cloudx.co.in](https://cloudx.co.in)

Personal portfolio of **Anjul Upadhyay** — Cloud & DevOps Engineer (GCP | AWS | OCI), Bangalore.

## Stack

- Pure HTML / CSS / JS — zero build step, zero dependencies
- Live project cards fetched from the GitHub API at page load
- Animated particle-network canvas, typing effect, terminal boot sequence
- Hosted on **GitHub Pages**, DNS by **Cloudflare** (`cloudx.co.in`)

## Local development

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Push to `main` — GitHub Pages does the rest.

```bash
git push origin main
```
